📦 How to Install & Run

Clone the repo and run the Python script — zero dependencies required.

Terminal 
git clone https://github.com/Chenboda01/Rock-paper-scissors.git
Terminal 
cd Rock-paper-scissors
Terminal 
python rock-paper-scissor.py

🎮 How to Play

  • Type r for rock, p for paper, s for scissors.
  • Press Enter to throw your hand.
  • Type y to play again or n to quit.
  • Rock beats scissors, scissors beats paper, paper beats rock.
